# Yiyang Zhao

This repository contains the source code for [Yiyang Zhao's academic homepage](https://YiyangZHA0.github.io). It is built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template, loaded as a remote theme, and hosted with GitHub Pages.

The homepage presents a profile focused on research experience and honors.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000`.
